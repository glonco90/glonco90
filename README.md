### Michal Glonek

Web developer based in Bratislava, Slovakia. I build websites, e-shops and custom applications for clients — from WooCommerce stores and custom plugins to standalone apps in Nette and Laravel. What I enjoy most is connecting systems through APIs and automating work that would otherwise be done by hand.

**What I do**

- 🛒 E-commerce — WooCommerce stores, product feeds (Heureka, Biano), analytics (GA4, GTM), performance and caching
- 🧩 Custom development — WordPress plugins and themes, PrestaShop themes from Figma, standalone apps in Nette and Laravel
- 🔌 Integrations — REST APIs, Microsoft 365 sign-in, invoicing systems, data imports and exports
- 🤖 Automation & AI — LLM-powered data processing, safe automated workflows across ~100 client websites
- ✅ Quality — automated tests and browser checks with Playwright before anything goes live
